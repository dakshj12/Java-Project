# Student Registration System using JDBC

A Java student-registration project intended to practice database connectivity with JDBC.

## 🎯 Objective

Connect a Java application to a relational database and work with student registration data.

## 🧠 Concepts

- JDBC connection setup
- SQL queries and database operations
- `Connection`, `PreparedStatement`, and `ResultSet`, where used
- Input validation and exception handling

## 🛠️ Requirements

- A compatible JDK
- A database server such as MySQL, if configured by the project
- The matching JDBC driver
- Database/schema created for this project

## 🚀 Setup

1. Open the project in your Java IDE.
2. Check the source code for the expected database name, table names, and driver.
3. Create the required database and tables.
4. Configure database connection settings locally.
5. Add the JDBC driver to the project's classpath.
6. Run the class containing the `main` method.

## 🔐 Security

Do not commit real database passwords. Prefer local configuration or environment variables.

## 📌 Notes

Use the actual schema and class names found in this folder. No database credentials or table definitions are assumed in this README.
