# JSP and Servlet Project

A Java web-development practice project using JSP and/or Servlets.

## 🎯 Objective

Understand how a Java web application receives HTTP requests, processes them on the server, and returns a response to the browser.

## 🧠 Concepts

- Servlet request and response handling
- Form parameters and HTTP methods
- JSP views and dynamic output, if used
- Request forwarding or redirects, if implemented
- Deployment to a servlet container

## 🛠️ Requirements

- JDK compatible with the project
- Apache Tomcat compatible with the servlet API
- Maven or an IDE project configuration, if required

## ▶️ Run

1. Open this folder and inspect its project configuration.
2. Identify the web application context and entry-point servlet/JSP.
3. Configure the supported Tomcat server.
4. Deploy the application and open its configured URL in a browser.

If the project has a `pom.xml`, check its packaging and dependencies before running `mvn clean package`.

## 📌 Notes

The exact pages, servlet mappings, and build commands depend on the files in this folder. Add those details after verifying the implementation.
